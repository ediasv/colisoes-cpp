# C++/SFML Ball Collision Simulation

A simple 2D simulation of multiple colliding balls, built in C++ using the [SFML](https://www.sfml-dev.org/) library.

This project demonstrates basic 2D physics for many objects on screen. Each ball moves with its own velocity and interacts with the boundaries and other balls.

### Core Features:
* **Movement:** Each ball's position is updated each frame based on its velocity.
* **Wall Collisions:** Balls detect and bounce off the edges of the window.
* **Ball-to-Ball Collisions:** The simulation includes detection and response for collisions between balls.
